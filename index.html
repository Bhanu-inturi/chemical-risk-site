Chemical Explosion Risk Predictor

Random Forest classifier trained on the UCI Gas Sensor Array Drift Dataset (128 sensor features, 16 MOX sensors)

Load a real sensor reading

Each button loads an actual row from the dataset's held-out test set (all 128 features) and runs the model on it.

Top sensor readings

The 10 features the Random Forest relies on most. Drag them to see how the prediction changes; the other 118 features keep the values of the reading you loaded.

Inputs are the dataset's sensor-response features (steady-state resistance change and exponential-moving-average rise/fall features), not raw ppm. Risk classes are relative, per gas: Safe / Caution / Danger are the low / middle / high thirds of that gas's concentration range in the dataset. The model was exported from the trained scikit-learn classifier with m2cgen and runs entirely in your browser.
